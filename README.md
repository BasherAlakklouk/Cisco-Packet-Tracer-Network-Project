# Complex Enterprise Network Topology & Subnetting 🌐

A multi-router enterprise network design developed as a **University Project** at the **University College of Applied Sciences (UCAS)**.

---

## 📊 Network Topology Overview

![Enterprise Network Topology](Screenshot%202026-10-14%20144055.png)

The network is divided into 4 main zones:
1. **Dev Department**: Development workstations with DHCP.
2. **Sales Department**: Sales team workstations.
3. **HR Department**: Human Resources workstations.
4. **Core Router & Data Center**: Houses Web-Server, FTP-Server, and DNS-Server.

---

## 🛠️ Key Features

- **Subnetting (VLSM)**: Optimized IP allocation across all departments.
- **Routing**: Inter-department communication via serial WAN links.
- **Services**: DNS, HTTP/Web, FTP, and DHCP.
- **Security**: Access Control Lists (ACLs) for traffic filtering and server access control.
